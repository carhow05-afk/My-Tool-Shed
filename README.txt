MY TOOL SHED — install on your Pixel 10 Pro

1. Unzip the folder on your computer.
2. Upload all the files INSIDE the tool-inventory-app folder together to a website using HTTPS.
   GitHub Pages is a free hosting option; upload these files to the root of a public repository and enable Pages under Settings > Pages > Deploy from branch > main / (root).
3. Open your GitHub Pages URL in Chrome on your Pixel 10 Pro.
4. Tap Chrome's three-dot menu > Add to Home screen > Install (or Add).
5. Open My Tool Shed from your home screen. It works offline after the first online load.

IMPORTANT
- All tool data and photos are kept in local browser storage on THAT phone (not uploaded to GitHub).
- Download JSON backups via Settings regularly; losing/clearing Chrome site data can erase records.
- Keep the same website URL to continue accessing existing records.
- Opening index.html directly from Files can be used to try the app, but install/offline PWA needs hosting on HTTPS.

This version does not include purchase date or purchase price fields.
